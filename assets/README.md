# assets/

Identidade visual compartilhada: uma subpasta por projeto (`assets/<projeto>/`), com o logo, as cores e as fontes.

**Dono único.** Os projetos apontam para cá; ninguém duplica o logo. Se um deploy isolado precisar de cópia, a cópia é aprovada por quem é dono do OS e anotada em `assets/<projeto>/README.md`, que manda reexportar todas quando o logo mudar.
